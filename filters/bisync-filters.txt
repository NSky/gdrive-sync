# gdrive-sync bisync filters
# Customize this file to exclude files from syncing.
# After changing it, run gdrive-sync-full once: rclone bisync needs a
# fresh baseline whenever the filters change.
# See: https://rclone.org/filtering/

- ~$*
- ~*.tmp
- .~lock.*

# === System junk ===
- .DS_Store
- Thumbs.db
- desktop.ini
- .Trash-*
- *.swp
- *.swo
